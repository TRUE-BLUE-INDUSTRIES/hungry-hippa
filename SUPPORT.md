# Supporting Hungry Hippa

Hungry Hippa is local-first, user-owned memory infrastructure. Support would sustain
open-source work on reliable conversation imports, traceable evidence, security
regressions, reproducible benchmarks, documentation, and connections to AI clients.
The [roadmap](ROADMAP.md) records priorities and the [project state](PROJECT_STATE.md)
records completed work and known gaps.

Sponsorship is intended to fund this public work. It will not unlock private product
functionality or access to anyone's memories. Contributions, reproducible bug
reports, documentation improvements, and tests are useful today; see
[CONTRIBUTING.md](CONTRIBUTING.md). Do not put private conversations, credentials, or
database backups into public issues.
