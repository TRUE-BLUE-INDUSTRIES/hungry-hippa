## Metrics that could not be measured

- **natural-language answer quality** — grading here is exact token matching on the assembled context; judging whether an answer is well phrased or subtly correct needs a model to judge, which would make the harness non-deterministic and network-dependent
- **semantic-equivalence recall (paraphrase matching)** — would need an embedding model or an LLM judge; vectors are disabled so the run stays offline and repeatable
- **embedding/vector recall quality** — local embeddings require an Ollama server; enabling them would make results depend on a model version, so the harness pins vectors off and reports keyword+graph recall only
- **baseline poison resistance (scenario 8, without arm)** — the baseline has no persistent store, so it cannot be poisoned and there is no comparable result — scored unsupported, not zero
- **baseline permission-denial accuracy (scenario 9, without arm)** — the baseline has no access control, so denial accuracy is undefined for it — scored unsupported, not zero
- **multi-user / cross-tenant isolation** — not implemented in the runtime, so there is nothing to measure
