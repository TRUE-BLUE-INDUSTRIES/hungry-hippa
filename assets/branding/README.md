# Hungry Hippa brand asset

The maintainer selected this supplied artwork as the project's logo on
2026-09-18. It is the visual reference for the repository, demo material,
support page and future Control Center.

- Canonical file: [hungry-hippa-logo.png](hungry-hippa-logo.png)
- Native size: 1254 × 1254 pixels, RGB PNG
- SHA-256: `73579d1d7e947fd4b253c67b638a6af0aae34c2af704d87b180c7f5d53a9807e`
- Original bytes are preserved, including the black background and wordmark.

Use relative repository paths, descriptive alt text and proportional display
sizing. The README uses 320 × 320 pixels; demo/support pages use 192 × 192.
Reference this master for future assets instead of generating a competing logo.
The visible palette is cyan, lime green and purple on black; future UI colors
should preserve readable text and contrast independently of the artwork.

The image previously linked from main remains available as the [original README artwork](https://github.com/user-attachments/assets/24e27307-8725-43bf-b230-5fbb41b34fd5). The integration README uses the checked-in approved logo above.
